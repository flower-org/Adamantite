## Onboard LAN to USB demo

The `demo/onboard-lan-and-usb` firmware branch can be used as a simple onboard Ethernet demo:

- the STM32H7 onboard RMII MAC is started directly from `Adamantite/Core/Src/main.c`
- received LAN packets are counted since boot in `demo_packet_count`
- each received packet triggers a USB CDC message formatted like `got packet <count>`
- the status LED on `PG7` toggles whenever a packet is observed

This is intended as a minimal packet-observation demo rather than a full networking stack.
