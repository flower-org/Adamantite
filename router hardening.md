Защита роутера с устойчивой конфигурацией:

- сделать прошивку неизменяемой - основной flash - read only;
- конфигурация хранится на SD карте;
- конфигурация подписывается приватным ключом пользователя;
- прошивка хранит в себе публичный ключ пользователя;
- при загрузке роутера вначале читается конфигурация с SD карты, и если подпись неверна, роутер не стартует, а сигнализирует об ошибке через sniffer.

Таким образом, мы достигаем следующих улучшений по безопасности:
- для атакующего невозможно произвести перманентные изменения в прошивке, т.к. она read-only;
- при попытке атакующего изменить конфигурацию на SD карте, будет невозможна ее загрузка, т.к. приватный ключ пользователя не будет доступен для подписи.
    - любая попытка смены конфигурации будет замечена, роутер при этом не запустится.
 
Неудобства - создание кастомной прошивки с пользовательским публичным ключом.
